Real-Time Character Counter

A simple and responsive Real-Time Character Counter built using HTML, CSS, and JavaScript. It counts the number of characters entered by the user instantly while typing.

🚀 Features
Real-time character counting
Updates instantly as the user types
Simple and clean user interface
Responsive design
Lightweight and easy to use
🛠️ Technologies Used
HTML5
CSS3
JavaScript

💻 How to Run
Clone the repository:
git clone https://github.com/rajneeshvermat-lgtm/Real-time-Characters-counter.git
Open the project folder.
Open 01.html in your browser.
Start typing and see the character count update in real time.
🎯 Purpose

This project was created to practice JavaScript DOM manipulation, event handling, and real-time UI updates.

📸 Preview

The application displays the character count dynamically as the user enters text.
